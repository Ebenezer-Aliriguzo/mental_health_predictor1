# Mental Health Disorder Risk Predictor System

## Project Overview
The Mental Health Disorder Risk Predictor is an applied artificial intelligence web application designed to evaluate an individual's statistical risk of requiring mental health treatment based on demographic characteristics, workplace environmental factors, and organizational mental health support structures. Built as a capstone project for the Professional Diploma in Artificial Intelligence at Cosmopolitan University, Abuja, this system bridges predictive analytics and digital health accessibility.

## Live Application & Integration
* **Streamlit Web Application:** [https://mentalhealthpredictor1.streamlit.app/](https://mentalhealthpredictor1.streamlit.app/)
* **Integrated Web Portal:** [https://www.aboveskye.com/health](https://www.aboveskye.com/health) (Navigate via "Mental Health Test Free" and "Take the Test")

## Architecture & Technology Stack
* **Programming Language:** Python 3.9+
* **Web Framework:** Streamlit
* **Machine Learning & Data Processing:** Scikit-Learn, Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Deployment Platform:** Streamlit Community Cloud
